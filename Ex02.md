## AIM   
To write a lex program to implement lexical analyzer to recognize a few patterns.

## ALGORITHM
1.Start the program.
2.Create a Lex program consisting of three sections: Declaration section, Translation rules section, and Auxiliary procedures section.
3.Include the necessary header files and define the patterns for keywords, identifiers, numbers, operators, and special symbols in the declaration section.
4In the translation rules section, specify regular expressions to recognize different lexical tokens and define corresponding actions to display the recognized tokens.
5.Write the Lex program using a text editor and save it with the .l extension.
6.Compile the Lex program using the Flex tool to generate the C source file lex.yy.c.
7.Compile the generated C file using GCC to create an executable file.
8.Execute the program and provide an input expression or statement.
9.Verify whether the lexical analyzer correctly identifies and displays the different lexical tokens.
10.Stop the program.

## PROGRAM
```

%{
#include <stdio.h>
%}

%%
"int"|"float"|"char"|"if"|"else"|"while"|"return" {
    printf("Keyword: %s\n", yytext);
}

[a-zA-Z_][a-zA-Z0-9_]* {
    printf("Identifier: %s\n", yytext);
}

[0-9]+ {
    printf("Number: %s\n", yytext);
}

[+\-*/=] {
    printf("Operator: %s\n", yytext);
}

[;(),{}] {
    printf("Special Symbol: %s\n", yytext);
}

[ \t\n]+ {
    /* Ignore whitespace */
}

. {
    printf("Unknown Token: %s\n", yytext);
}
%%

int main()
{
    printf("Enter the input:\n");
    yylex();
    return 0;
}

int yywrap()
{
    return 1;
}



```
